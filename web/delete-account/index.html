Request deletion of your account and personal data

Before you start

This page deletes the Swachham customer account registered to a mobile number. You do not need the app installed.

Submitting this form does not delete anything on its own. We send a 6-digit code to the mobile number to confirm the request really comes from the account holder. The deletion happens only after you enter that code.

What is deleted, and what is kept

  • Deleted: your name, email address, mobile number, password, profile photo, saved addresses, cart, notifications and reviews.
  • Kept: records of orders you have already placed. We are required to retain billing and tax records, so those rows stay — but they are detached from your identity and no longer name you.
  • If you have never placed an order, the account is removed outright and nothing is kept.

This cannot be undone. To use Swachham again afterwards you would need to register a new account.

Step 1 — Request the code

The number you sign in with. Indian mobile numbers only; +91 and spaces are fine.

Step 2 — Confirm the deletion

Sent to the number you entered above. It expires shortly.

Need help?

If you cannot receive the code — for example the number is no longer in use — email info@swachham.co.in from the address on the account and we will verify the request another way. We aim to respond within 30 days.
